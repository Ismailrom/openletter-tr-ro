# OpenLetter TR–RO

**Open-source Turkish–Romanian correspondence templates for small businesses and individuals.**

OpenLetter TR–RO is an early-stage open-source project focused on providing practical correspondence templates between **Turkish and Romanian**.

The project aims to make common written communication easier for individuals and small businesses that need to communicate across Turkish- and Romanian-speaking contexts.

> **Project status:** Early development / concept stage  
> There are currently no users, download statistics, or adoption figures being claimed.

## Why OpenLetter TR–RO?

Cross-border communication often involves repetitive documents and messages such as:

- Business inquiries
- Customer and supplier correspondence
- Requests and responses
- Appointment and service-related messages
- Formal notices
- General-purpose letters and emails

Creating these documents from scratch can be time-consuming, particularly when communication involves two languages.

OpenLetter TR–RO aims to provide reusable templates that can be adapted to specific situations rather than requiring users to start from an empty document each time.

## Languages

The initial project scope covers:

- 🇹🇷 Turkish
- 🇷🇴 Romanian

Templates may be provided in one or both languages depending on the use case.
